# Employee API

Simple Employee CRUD API built with Express and MongoDB, documented using Swagger.

## Features
- Create employee
- Get all employees
- Get employee by ID
- Update employee
- delete employee ( Soft )

## Tech Stack
- Node.js
- Express
- MongoDB + Mongoose
- MySql / Postgres

## Deployed

- Render
- AWS Lambda
- AWS Beanstalk
- Supabase
- Netlify
- Vercel
